# 삼슐랭 가이드 · 무료 배포 데모

2026 DISCOVER B-2조(삼슐랭) 과제 앱이에요. 신입 회계사가 현장 근처 맛집을 등록·공유·추천해요.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면 전체 (S01 홈 · S02 등록 · S03 찾기 · S04 족보 커뮤니티 · S05 족보 검색) |
| `api/config.js` | Vercel 환경변수에서 **공개용 키만** 꺼내 앱에 전달 (비밀키가 들어오면 막음) |
| `vendor/supabase.js` | Supabase 연결 도구 (supabase-js 2.117.2, MIT) |
| `vercel.json` | 보안 헤더 설정 |
| `supabase_schema.sql` | Supabase 표·규칙 (SQL Editor에서 이미 실행함) |

## Vercel 환경변수 (Settings → Environment Variables)

| 이름 | 값 |
|---|---|
| `SUPABASE_URL` | Supabase Project URL (`https://xxxx.supabase.co`) |
| `SUPABASE_KEY` | Supabase **Publishable key** 또는 **anon public** 키 (secret/service_role 금지) |
| `KAKAO_JS_KEY` | 카카오 **JavaScript 키** (REST/Admin 키 금지) |

키는 이 저장소(GitHub)에 넣지 않아요.

## 데이터 원칙

- `[가상]`이 붙은 식당 58곳과 그 추천·팁은 샘플데이터 v3의 가상 값이에요.
- 사용자가 등록한 식당의 장소 정보는 카카오맵에서 가져와요(출처 표시).
- 로그인이 없어서 브라우저별 익명 ID로 하루 1회 추천을 구분해요(O3).
- 실명, 연락처, 고객사 정보는 입력하지 않아요.
- 지역 3곳(10/07): 용산·신용산(기준점 본사) · 양평 블룸비스타(시연 장소, 기존 양평 A 현장 자리) · 여의도(클라이언트 현장, 기준점 여의도역)
  - 지역 검증: 카카오에서 고른 식당은 기준점 반경(용산 2km · 블룸비스타 5km · 여의도 1.5km) 안이어야 등록돼요. 이름만 직접 입력한 식당은 "위치 미확인"으로 표시
  - 쓰려면 `supabase_schema.sql`의 **7) 지역 3곳 + 지역 검증** 부분을 SQL Editor에서 실행해야 해요(실행 전에는 여의도 등록이 안 돼요)

## 화면 구성 (10/06 기준)

- S01 홈: 족보 검색창 + 빠른 필터(도보 5분·혼밥 OK·빨리 나와요·팀 회식) → 맛집 찾기 / 맛집 등록 → 최근 3일 TOP 3(실시간)
- S02 맛집 등록: 카카오맵 장소 검색(안 되면 이름 직접 입력), 등록 시 등록자 추천 1개 자동 포함(A2)
- S03 맛집 찾기: 시간대·인원·가격대 → "오늘 여기!"
- S04 족보 커뮤니티: 추천(하루 1회), 방문 팁(닉네임 선택, 비우면 "익명 방문자")
- S05 족보 검색: 검색어 + 빠른 필터 + 종류 칩
- 사진 등록(10/07 팀 회의 확정): S02에서 대표 사진 1장(선택). 큰 사진(1080px)과 썸네일(400px, 파일명 끝 `_t`)을 함께 올려요
  - 썸네일: S01 TOP 3 · S05 족보 검색 목록 / 큰 사진: S03 "오늘 여기!" 결과 · S04 식당 소개
  - 사진이 없는 식당: 식당 종류·메뉴에 맞는 AI 예시 사진(`images/food/`, 썸네일 `images/food/thumb/`). 큰 사진에 "AI 예시 이미지" 표시
  - AI 사진 원본(`food_images/`)은 용량이 커서 GitHub에 올리지 않아요(`.gitignore`)
  - 쓰려면 `supabase_schema.sql`의 **6) 대표 사진** 부분을 SQL Editor에서 한 번 실행해야 해요(사진 컬럼 + Storage 버킷 `restaurant-photos`).
  - 실행 전에는 사진 없이 등록하는 기존 기능은 그대로 되고, 사진을 넣고 등록하면 "사진을 올리지 못했어요" 안내가 떠요.
